# Manual Test Script

## Public Visitor

1. Open the home page.
2. Open the event catalog.
3. Search and filter events.
4. Open an event detail page.
5. Submit a registration with valid consent.
6. Open public certificate verification and verify an active code.
7. Verify that a revoked code shows revoked status without private profile data.

## User

1. Sign in.
2. Complete profile fields.
3. Register for an event.
4. Open cabinet.
5. Start a published test within its availability window.
6. Submit answers.
7. Download certificate only when eligible.
8. Confirm material access changes by registration, attendance, and eligibility.

## Admin

1. Sign in as admin.
2. Create event and speaker.
3. Upload event materials.
4. Create and publish test.
5. Mark attendance.
6. Generate certificate.
7. Export participants and confirm metadata sheet exists.
8. Revoke certificate and confirm public verification updates.
