# BPR Regulatory Audit

## Covered In Code

- Event records include BPR points, hours, format, category, official registration number, specialties, and provider verification status.
- Registration, attendance, test pass state, and active certificate uniqueness determine certificate eligibility.
- Certificates include provider name and official registration number when available.
- Public verification supports active and revoked certificates while excluding private profile data.
- Participant exports include generation metadata.

## Requires Provider Approval

- Exact Ukrainian certificate wording.
- Consent and privacy text.
- Provider accreditation statements.
- Official BPR event registration numbers and specialty mappings.
- Retention schedule for certificates, attendance records, tests, and audit logs.

## Risk

Regulatory acceptance cannot be claimed until the provider approves the above items in writing.
