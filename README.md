# Continuing Professional Development Platform

A web application prototype for discovering professional education events, managing registrations and learning activities, and generating and verifying certificates.

The application source and detailed documentation are in [`holos-kyivshchyny-bpr-platform/`](./holos-kyivshchyny-bpr-platform/).

## Main workflows

- Public event discovery and registration.
- Learner accounts, learning materials, tests and certificate access.
- Certificate generation and public verification.
- Administrative event, registration and content management.
- Ukrainian and English interface content.

## Technology

Next.js, React, TypeScript, Tailwind CSS, Prisma and PostgreSQL; Vitest and Playwright for testing.

## Status

This is an MVP/prototype. Demo workflows and production integration requirements are documented in the application README. Authentication, database, email and other deployment services must be configured and reviewed before real-world use. Sample accreditation documents are demonstration material.

For local setup, start in the application directory and follow its README.
